## 🚀 Overview

Family & Friends is a modern AI-powered messaging platform that combines real-time communication, voice & video calling, intelligent automation, conversation analysis, task extraction, and productivity-focused messaging into a single unified experience.

Unlike traditional messaging apps that focus only on communication, Family & Friends helps users organize conversations, track commitments, remember decisions, manage tasks, and stay informed even when they are unavailable.

## 🤝 Agent Mode

An intelligent assistant that helps when you're unavailable.

### Agent Behavior

Instead of pretending to be you, Agent Mode:

- Informs contacts you're unavailable
- Notes important requests
- Collects information
- Extracts tasks
- Tracks commitments
- Generates "While You Were Away" summaries
- Follows instructions configured inside AI Hub

### Example

Contact:

> "Can you send me the chemistry notes?"

Agent:

> "Ishrit is currently unavailable. I've noted your request and will make sure they see it when they're back."
