## AI AutoPilot

When you're away, AutoPilot can:

- 🤝 Inform others you're unavailable
- 📝 Collect important information
- ❓ Ask follow-up questions
- 📌 Capture commitments & tasks
- 📚 Prepare a "While You Were Away" summary
- 🧠 Follow instructions configured inside AI Hub
- 👤 Hand conversations back naturally when you return
